# Global Definition of Done

A story is not Done unless all applicable items pass:

- Business rule implemented.
- Database migration/versioning handled.
- Backend behavior implemented.
- API contract documented.
- Server-side authorization enforced.
- Responsive UI completed.
- Arabic and English validated.
- RTL/LTR validated.
- Validation and error states implemented.
- Audit event implemented when sensitive.
- Unit tests pass.
- Integration tests pass.
- UI/e2e test exists for critical workflow.
- Existing test suite remains green.
- No critical console/runtime errors.
- Acceptance criteria demonstrated.
- Documentation updated.
- No unrelated refactor or dependency introduced without justification.
