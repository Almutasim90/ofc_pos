# OFC Agile Delivery Pack

هذا المجلد يحول البرومت المتكامل إلى نظام تنفيذ منضبط.

## Start Here
1. `00-MASTER-SRS.md` — مصدر الحقيقة.
2. `01-ARCHITECTURE-GUARDRAILS.md` — قواعد المعمارية.
3. `02-UI-DESIGN-SYSTEM.md` — قواعد التصميم والاستجابة.
4. `03-PRODUCT-BACKLOG.md` — خارطة الإصدارات والـSprints.
5. `04-GLOBAL-DEFINITION-OF-DONE.md` — تعريف الإنجاز.
6. `05-STORY-EXECUTION-TEMPLATE.md` — قالب إعطاء Story لوكيل البرمجة.
7. `/sprints` — Sprint 00 إلى Sprint 18.

## Execution Rule
لا تعطِ وكيل البرمجة المشروع كله دفعة واحدة.
أعطه Story واحدة، مع ملفات المرجعية، واطلب منه Implement ONLY تلك الـStory.
